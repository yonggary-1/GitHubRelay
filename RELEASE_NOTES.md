## GitHub Relay v0.9

- **Update now**: when a newer version is found, GitHub Relay can download it, verify it (size, SHA-256 published by GitHub, Windows program header), replace itself and restart automatically. Your data file is not touched, and a failed update leaves the current version in place
- The update notice says that the program restarts automatically
- Updating is blocked while an upload or batch is running
- Includes the v0.8 changes: deleting newer releases when reverting, and reverting the code when deleting the latest release
